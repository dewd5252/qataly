# خطة تنفيذ تحسينات UX — تطبيق قطعلي

**المرجع:** كل النقاط دي مؤكدة من استكشاف الكود الفعلي (مش من المستند بس)، واتضافت ليها 3 bugs خلفية اكتشفتها.

## المرحلة 0 — SQL Migration (تُطبَّق على Supabase)

ملف جديد `supabase_ux_migrations.sql` ينفَّذ في SQL Editor:
1. **RPC `increment_weak_word(user_id, word)`** — إدخال/تحديث بزيادة `mistake_count + 1` بدل ما يترجع لـ 1 (إصلاح bug العدّاد).
2. **سياسة قراءة profiles** — `FOR SELECT USING (true)` لـ role authenticated (بدونها لوحة المتصدرين ولوحة المعلم مش هترجّع غير صف المستخدم نفسه).
3. **RPC `top_weak_words(classroom_id, limit)`** — تجميع أكثر الكلمات ضعفًا لطلاب الفصل (word, mistakes, students) — مطلوبة لعرض حقيقي في Teacher Dashboard.

*ملحوظة: مكسب MMR للمذكرة هيتصلح client-side (سياسة profiles_owner بتسمح بتحديث الصف الشخصي) — مش محتاج migration.*

## المرحلة 1 (P0) — الاستخدام اليومي الحرج

### 1A. شاشة البداية + شاشة الخطأ
- **`splash_screen.dart`**: إضافة مؤشر تحميل (CircularProgressIndicator بلون secondary) + نص حالة متحرك "جاري تجهيز جلستك..." تحت اللوجو بعد انتهاء الأنيميشن (~1.5 ثانية). توحيد لون الخلفية مع `QatalyTheme.background` (حاليًا مختلف).
- **`main.dart` `_SupabaseErrorScreen`**: تحويلها لـ stateful + زر "إعادة المحاولة 🔄" (BrutalistButton) يعيد تنفيذ `Supabase.initialize` وعند النجاح ينتقل لـ SplashScreen. إصلاح `textAlign` للخطأ.

### 1B. شاشة التحدي — التحديد ثم التأكيد
- **`challenge_screen.dart`**: فصل "التحديد" عن "التأكيد" — أول ضغطة على الخيار تعمل selection فقط (highlight بلون primary + إطار)، ويظهر زر **"تأكيد الإجابة ✅"** هو اللي يقفل ويشغّل المنطق الحالي (كشف صح/غلط + shake + تفسير). الخيارات المقفل عليها لا تستجيب. الحالة local في الشاشة (`Set<int> _confirmed`).
- **شريط تقدم Brutalist**: LinearProgress بزوايا حادة أعلى منطقة الأسئلة + نص "أجبت X من 6" + صف نقاط لكل سؤال (أخضر=مؤكد، بنفسجي=محدد، رمادي=لم يُجب) — النقاط قابلة للضغط للتنقل.
- **حسم شاشة النتائج**: تبقى full-screen in-place swap (المعمارية الحالية) + إضافة `PopScope(canPop: false)` عشان زر الرجوع من النظام يخرج للـ Dashboard مش للاسئلة المجاوبة.
- **فشل التسليم صامت → SnackBar** بخطأ ودي عند فشل `submitChallenge` (حاليًا الخطأ بيتخزن ومحدش بيعرضه).
- **فشل توليد الـ AI (الطالب)**: في Arena، استبدال SnackBar الخام بـ **كارت خطأ inline** داخل كارت التحدي: "تعذر توليد التحدي ⚠" + زر "حاول مرة أخرى" + زر "قطعة جاهزة من المستر" يستخدم `_availablePassages` (المجلوبة أصلًا وغير المستخدمة) كـ fallback.
- **تنظيف رسائل الأخطاء** في `gemini_service.dart`/`challenge_provider.dart`: إخفاء أجسام الـ API الخام (Groq 500...) واستبدالها برسائل عربية واضحة.

### 1C. وضوح ميزة الترجمة (Double-tap)
- **Coach-mark أول مرة**: SharedPreferences flag `hint_words_translate_seen` — أول تحدي يفتح تظهر بانر brutalist قابل للإغلاق فوق القطعة: "💡 اضغط مرتين على أي كلمة تترجمها فورًا".
- **إشارة بصرية**: كلمات القطعة تأخذ dotted underline خفيف يدل إنها قابلة للتفاعل.

### 1D. حالة "خلصت تحدي اليوم" في Arena
- **`supabase_service.dart`**: دالة `getTodayProgress(userId)` — آخر صف في `user_progress` بتاريخ النهاردة.
- **`challenge_provider.dart`**: `completedToday` + `todayProgress` + `checkDailyCompletion()` تُنادى في `initState` للداشبورد وبعد الرجوع من شاشة النتائج.
- **UI**: عند الاكتمال → الكارت يتحول لوضع "تم إنجاز تحدي اليوم 🎉" (شارة "مكتمل ✅") + ملخص النتيجة (الدرجة % وتغيير الـ MMR) + **عداد تنازلي حي** (Timer) لمنتصف الليل "التحدي الجديد بعد س:د:ث" + إخفاء زر البدء.

## المرحلة 2 (P1) — Vault / Leaderboard / Teacher

### 2A. Vault
- **ترتيب**: chips تبديل "الأكثر خطأً 🔥" (الحالي من الـ DB) / "الأحدث 🕐" (lastSeen desc — الحقل مجلوب وغير معروض حاليًا).
- **بحث**: BrutalistInput يفلتر بالكلمة.
- **"أتقنتها ✅"**: زر لكل كلمة → `removeWeakWord(userId, word)` (delete) + إزالة متفائلة + SnackBar "تراجع".
- **إصلاح العدّاد**: ربط `recordWeakWord` بالـ RPC `increment_weak_word` (مع fallback للسلوك الحالي لو الـ RPC مش موجود).
- إضافة RefreshIndicator.

### 2B. Leaderboard
- **تبديل عالمي/فصلي**: زرّين brutalist أعلى التبويب — "عالمي 🌍" (الحالي) / "فصلي 🎓" يفعّل `loadClassroomData(classroomId)` (الدالة موجودة وميتة). لو مفيش فصل: empty state "انضم لفصل من الإعدادات" + زر ينقل لتبويب Settings.
- **"ترتيبك"**: لو المستخدم مش ضمن القائمة المعروضة → كارت أسفل اللist "ترتيبك: #N" عن طريق count query (mmr أكبر من المستخدم + 1) — دالة `getGlobalRank(userId)`.

### 2C. Teacher Dashboard
- **الإصلاح الحرج**: `initState` ينادي `stats.loadClassroomData(classroomId)` (الداشبورد حاليًا بتحمّل صفر بيانات وبتعرض 0/0/0 وجدول فاضي).
- **أكثر 5 كلمات ضعفًا حقيقية**: `getTopWeakWords(classroomId)` → RPC المرحلة 0، مع empty state بدل الـ hardcoded list.
- **CSV حقيقي**: إضافة `share_plus` + `path_provider` — توليد ملف `qataly_students_YYYYMMDD.csv` بـ **UTF-8 BOM** (عشان العربي في Excel) + `Share.shareXFile` + إبقاء "نسخ للحافظة" كزر ثانوي. حذف الـ delay الوهمي (600ms).
- **جدول الطلاب**: حقل بحث بالاسم + ترتيب بالضغط على عمود MMR/Streak + drill-down: ضغط الصف يفتح dialog بتفاصيل الطالب + آخر 5 من `user_progress` (دالة `getStudentProgress`).

## المرحلة 3 (P2) — RTL + Onboarding

### 3A. الاتجاه والتعريب
- **`pubspec.yaml`**: + `flutter_localizations` (sdk) + `intl`.
- **`main.dart`**: `locale: Locale('ar')` + `supportedLocales: [ar, en]` + delegates — الـ layout كله يقلب RTL صح.
- **لف المحتوى الإنجليزي**: `Directionality(ltr)` حول منطقة القطعة الإنجليزية في شاشة التحدي + الكلمات المترجمة + أسماء الرتب ("Bronze I") في كل الشرائح (Arena/Leaderboard/Settings/Teacher).
- مراجعة يدوية لكل الشاشات بعد القلب (ترتيب الـ Rows، أسهم الرجوع، الـ SnackBars).

### 3B. Onboarding
- شاشة جديدة `onboarding_screen.dart`: PageView بـ 4 شرائح brutalist: (1) التحدي اليومي والـ MMR، (2) الرتب والسلسلة 🔥، (3) قاموس ضعفك + الترجمة بالضغطتين، (4) VIP. نقاط تقدم + "تخطي" + "يلا نبدأ 🚀".
- **التشغيل**: flag `onboarding_completed` في SharedPreferences — تظهر مرة واحدة بعد أول تسجيل دخول ناجح (ومن استعادة الجلسة للي مش شافهاش) قبل الداشبورد.
